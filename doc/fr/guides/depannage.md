# 🛠️ Dépannage & FAQ

Vous avez trouvé un bug ou vous avez des difficultés ? Voici les solutions les plus courantes.

## 📱 Problèmes de Connexion WhatsApp
**Problème** : Le statut est "DISCONNECTED" ou le code QR ne se charge pas.
- **Solution 1** : Assurez-vous que votre téléphone a une connexion internet stable.
- **Solution 2** : Déconnectez-vous de toutes les autres sessions "WhatsApp Web".
- **Solution 3** : Redémarrez la connexion depuis la page **Paramètres > WhatsApp**.

## 💰 Échecs de Vérification de Paiement
**Problème** : Un client a envoyé un reçu, mais le Payment Shield ne l'a pas validé.
- **Solution 1** : Assurez-vous que la capture d'écran est claire et montre l'ID de transaction.
- **Solution 2** : Vérifiez si le numéro destinataire sur le reçu correspond à vos numéros de paiement configurés.
- **Solution 3** : Effectuez une **Validation Manuelle** en cliquant sur l'icône "$" sur la commande.

## 🤖 L'IA donne de mauvaises informations
**Problème** : L'IA cite de mauvais frais de livraison ou des prix obsolètes.
- **Solution** : Allez dans **Paramètres > Base de Connaissances**. Assurez-vous que vos zones de livraison et votre FAQ sont à jour. L'IA utilise ces données comme sa "Bible".

## 🚀 L'application semble lente
- **Solution** : Vendeur IA est une PWA. Essayez de vider le cache de votre navigateur ou de réinstaller l'application sur votre écran d'accueil pour de meilleures performances.

## 📞 Besoin d'aide supplémentaire ?
Utilisez le **Widget Copilot** dans le tableau de bord pour discuter avec notre IA de support, ou utilisez l'option "Contacter les Fondateurs" pour les problèmes critiques.

# 🚀 VENDEUR IA — Agent Operating Protocol (Finalisation & Excellence)

Dernière mise à jour : 2026-07-30 UTC

Ce protocole est **obligatoire** pour tout agent IA, assistant ou développeur intervenant sur **VENDEUR IA OS**. Il définit les standards de rigueur, de qualité et de finition nécessaires pour transformer l'application en une machine de vente de classe mondiale.

---

## 💎 Principe Fondamental : "Logic-Perfect" avant "Pixel-Perfect"

L'objectif est la **fiabilité absolue du moteur de vente**. Chaque interaction entre l'IA, le marchand et le client final doit être sans faille.

**Mandat Zéro UI Morte :**
- **Aucune simulation de façade** : Tout bouton visible doit être fonctionnel.
- **Données Réelles** : Pas de texte statique là où l'IA doit agir (Prix, Stocks, Canaux de paiement).
- **Zéro Hallucination** : L'IA ne doit utiliser QUE les données configurées par le marchand dans son "Cerveau IA".

## 📱 Standards de Qualité OS

### 1. Excellence Mobile-First
- L'interface doit être utilisable à **un seul pouce**.
- Chargement instantané et gestion gracieuse des états `Offline`.

### 2. Flux de Paiement Sacré
- Le marchand doit être notifié en **temps réel** pour chaque intention d'achat.
- L'affichage des numéros **Wave, Orange, MTN** doit être d'une clarté absolue.

### 3. Intelligence de l'Agent
- Les réponses de l'IA doivent être **locales, concises (max 60 mots)** et orientées conversion.
- L'IA doit savoir passer la main à l'humain (`Human Takeover`) dès qu'une preuve de paiement est détectée.

## ✅ Definition of Done (Vendeur IA)

Une tâche est déclarée "Terminée" uniquement si :
1.  **Fonctionnalité réelle** : Testée avec de vraies requêtes API.
2.  **Zéro MaatFeed** : Aucune dépendance ou référence aux anciens modules sociaux.
3.  **Rendu Mobile** : Validé sur écran étroit.
4.  **Doc Sync** : La progression est tracée dans l'historique des tâches de `MEMORY.md`.

## 🛑 Règle d'Or Finale
**Vendeur IA n'est pas un jouet, c'est un employé.** Chaque ligne de code doit servir à faire gagner de l'argent au marchand. Si une modification ne contribue pas directement à la vente ou à la clarté du Dashboard, elle est rejetée.

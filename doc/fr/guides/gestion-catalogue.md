# 📦 Gestion du Catalogue & Inventaire

Gérer vos produits efficacement est la clé pour des taux de conversion élevés. Vendeur IA fournit des outils pour rendre cela sans effort.

## 📸 IA Vision (Photo-en-Produit)
Au lieu de taper chaque détail, prenez simplement une photo de votre produit.
- **Article Unique** : L'IA se concentre sur les détails, le tissu et le style.
- **Scan en Lot** : Prenez une photo d'une étagère ou d'une collection. L'IA identifiera plusieurs articles et créera des brouillons pour chacun.

### Conseils pour de Meilleurs Résultats :
- Utilisez un bon éclairage.
- Placez le produit sur un fond neutre.
- Incluez les étiquettes de prix dans la photo si possible ; l'IA les lira !

## ✍️ Copywriting Intelligent (Légendes)
Chaque produit a un bouton "Étincelles". Cliquez dessus pour générer :
- **Légendes Instagram/TikTok** : Optimisées pour l'engagement avec des hashtags pertinents.
- **Ton Local** : Choisissez entre un style professionnel, amical, ou "Nouchi" (style urbain ivoirien).

## ⭐ Articles en Vedette
Sélectionnez vos meilleures ventes pour qu'elles apparaissent dans le **Hero Showcase** sur votre vitrine publique. Ces articles bénéficient de 3x plus de visibilité.

## 📉 Suivi des Stocks
- Marquez les articles comme "Rupture de stock" pour empêcher l'IA de les suggérer.
- L'IA vous alertera automatiquement lorsqu'un article populaire est presque épuisé.
